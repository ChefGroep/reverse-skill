## Full Execution Chain

1. Merge the completed translation branch into the main line and push; CI immediately reports two failing jobs.
2. Fix layer 1: non-ASCII `.ps1` scripts lost their UTF-8 BOM in the translation pass; prepend a BOM to the flagged files.
3. Fix layer 2: the coherence gate greps for literal contract phrases; restore the exact strings (`iron law`, en-dash recipe tokens, evidence-preservation phrasing, delta-consumer contract) in the six affected docs.
4. Fix layer 3: the generated-index check still fails. A hand-written replica of the generator is attempted twice and both times disagrees with the real tool (relative link format, then sort order).
5. Install the real PowerShell 7 runtime locally, run the actual generator with `DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1` to match the runner, regenerate the index, and self-verify with the script's own `-Check` mode before pushing.
6. Verify the final run with an unmasked exit code: all jobs green.

## Pitfall Log

| Problem | Cause | Solution | Time |
|------|------|---------|------|
| CI reported success while the run was still red | `gh run watch --exit-status \| tail` — the pipeline returns the last command's exit status, not the watched run's | capture the exit code in the same command (`echo EXIT=$?`) or write to a file before piping | ~15 min wasted on a false green |
| Python replica of the generator failed twice | the real script writes a UTF-8 BOM and sorts with invariant culture (lowercase sibling dirs before parent `SKILL.md`); codepoint sorting disagrees | install the actual runtime and run the real script with `DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1` | ~2 failed pushes |
| Corrupted-output turns left uncommitted damage in the worktree (rewritten rules doc with garbage text, wrong index replica) | agent output corruption mid-task | after any anomalous turn, read `git status` and the diff before committing anything; revert damage with `git checkout --` | caught before a bad push |

## Toolchain Findings

- `pwsh` runs fine from a plain tarball extraction (`~/.local/pwsh`); only `chmod +x` is needed after extraction.
- `-Check` mode of a generator is the correct local gate: it reproduces the CI check byte-exactly, so push-and-see is never required.
- `gh run watch --exit-status` is trustworthy only when its exit code is captured without a downstream pipe command masking it.
