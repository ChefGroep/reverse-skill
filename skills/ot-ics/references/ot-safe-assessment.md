# OT Safety Assessment Checklist

1. Authorization scope and emergency contacts  
2. Is active probing / write access allowed (default: no)  
3. Maintenance windows and rollback plan  
4. Traffic mirroring preferred over port scanning  
5. On a high-risk finding: immediately stop widening and escalate (site owner; NCSC-NL where in scope)  
6. Report distinguishes: remotely exploitable vs. requiring physical access  

Common protocol ports (for identification, not an exploitation manual): Modbus/TCP 502, S7comm 102, EtherNet/IP 44818, DNP3 20000.
