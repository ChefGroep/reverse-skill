# Tool Defaults

- `js-reverse_list_network_requests`: review the first page of default results before paging further
- `js-reverse_search_in_sources`: default `excludeMinified=true`
- `js-reverse_get_script_source`: read only small fragments; for full sources prefer `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: fill in only URL fragments that reliably hit
- `js-reverse_get_paused_info`: default to checking `frameIndex=0` first
